# booking-api

Backend Laravel del sistema di prenotazioni. Installazione, avvio, dati di prova e tabella delle API sono
nel [README principale](../README.md).

Comandi utili, da questa cartella:

```bash
./vendor/bin/sail up -d                  # avvia i container
./vendor/bin/sail artisan queue:work     # worker: senza, le email non partono
./vendor/bin/sail artisan test           # test
```
